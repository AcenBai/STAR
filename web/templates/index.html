Returning Users

New Users

  1. Enter a unique User ID.
  2. Choose Human, MLLM, or Radiologist as instructed.
  3. Add a model name or note if needed, then select Start / Resume.

Annotation Workflow

Answer each image in order: Q1 Region → Q2 Lymph Node → Q3 Site → Q4 Image Quality.

Choose one option and submit each answer. Progress is saved automatically.

Radiologists: Before starting, confirm your assigned Radiologist ID with the study administrator. Always use that same ID for every session. Do not select or enter another radiologist’s ID, as this will mix annotation records between participants.

Radiologists are automatically assigned one blinded, balanced image group. MLLM users receive the frozen No-issue benchmark; human users receive the complete manifest.
